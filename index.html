ATECMI – Solutions de Conditionnement Industriel

Refonte intégrale de la plateforme digitale pour un concepteur de lignes de conditionnement. L'objectif était de transformer un catalogue technique dense et complexe en une interface fluide, intuitive et résolument moderne. Django JavaScript HTML5 / CSS3 Tailwind CSS GitHub Optimisation Performance

Site Web Immersif & Multipage pour Restauration Premium

Conception et développement d'un template vitrine multipage haut de gamme, pensé pour les restaurants et structures touristiques cherchant une identité visuelle forte et cinématique. Le site intègre une expérience narrative forte (storytelling), une vitrine dynamique des menus et un système complet de réservation de tables en ligne directement connecté à un espace de gestion client. Un sélecteur de thème permet de basculer instantanément d'une ambiance lumineuse à un mode sombre intimiste.

Django HTML5 / CSS3 Tailwind CSS JavaScript Alpine.js Responsive Design PostgreSQL Mobile-First

Landing Page Ultra-Dynamique & Vendeuse

Création d'un template monopage (One-Page) à fort impact visuel, inspiré des tendances graphiques urbaines et du style néo-brutaliste. Conçu spécifiquement pour les commerces à forte rotation (snacks, pizzerias, camions-bars), ce site va droit au but sur mobile : affichage immédiat de l'état d'ouverture en temps réel, menu fluide avec filtres instantanés sans rechargement de page, et tunnels de conversion ultra-courts vers l'appel direct ou la commande par messagerie.
